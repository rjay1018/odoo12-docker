Download Custom Excel Report Using Excel Sheet As a Template

Key Features

You can Download your Custom Excel Report :-

  • Configuration & Setup
  • Demo Video

Click on the configuration and go to Settings

  • Then you can see the Tax Report Configuration inside that you can load your Sample Template and also Fill the fields.
Then You Open A Configuration and Go to Taxes

  • Here You can open Any Tax and Go to the Advanced option and here you can set Configuration of the particular Tax. Like You can add Tax Description and If that tax You can show in the Tax Report Then Tick that check box.
Then You open the Invoice menu and Create the Invoice

  • Now, You can add some product with different types of Tax.
  • Then, you can click on the Other Info Page.
Check the Tax Description on the Other Info Page.

  • Click on That Tax it will be open that Description.
Then Click on the Download Report Button.
