# Scorecard Basic - Font Awesome 4.7.0 Icons

## Available Font Awesome Icons

Scorecard basic now supports **30+ Font Awesome 4.7.0 icons** with unlimited potential via direct icon name input.

### Font Format
- **Full format:** `fa-iconname` (e.g., `fa-money`, `fa-users`)
- **Short format:** `iconname` (automatically converted to `fa-iconname`)
- Both formats work in the UI dropdown and direct input

## How to Use Custom Font Awesome Icons

### Method 1: Select from Dropdown (Easiest)
1. Edit scorecard → Icon Type dropdown
2. Choose from 30+ pre-configured options
3. Changes apply instantly

### Method 2: Enter Custom Icon Name (Advanced)

If you want to use an icon not in the dropdown:

1. Open scorecard configuration
2. In the **Icon Type** field, manually enter Font Awesome icon name
3. Use format: `fa-iconname` or just `iconname`
4. Press Tab or click outside to confirm
5. Changes apply instantly

**Examples of custom icons:**
```
fa-building          📌 For company/organization metrics
```

### Font Awesome Icon Browser

Find all available Font Awesome 4.7.0 icons at:
**http://fontawesome.io/icons/** (versions 4.0-4.7.0)

Simply search for an icon, copy its name (without the "fa-" prefix or with it), and paste into the Icon Type field.
